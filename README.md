# Private Office Server

Este repositório reúne a documentação da decisão final sobre a migração do compartilhamento de arquivos do escritório para uma solução mais prática e sustentável.

## Contexto

O projeto começou com a análise de uma solução baseada em servidor próprio, com compartilhamento de arquivos local e remoto. Após a avaliação de custos, complexidade operacional e manutenção, a solução adotada foi utilizar Microsoft 365 Business com um número reduzido de licenças para os usuários que realmente precisam de acesso.

## Decisão adotada

A opção final foi:

- usar Microsoft 365 Business em vez de montar um servidor próprio;
- reduzir o número de licenças para o escopo inicial;
- priorizar simplicidade, rapidez de implantação e menor esforço de manutenção;
- permitir escalonamento futuro caso a demanda aumente.

## Arquivos principais

- [migration-summary.md](migration-summary.md): resumo consolidado da evolução do projeto e da decisão final.
- [microsoft365-adopted-solution.md](microsoft365-adopted-solution.md): documento com a solução adotada e os motivos da escolha.

## Estrutura do repositório

- Documentação de decisão e contexto do projeto;
- arquivos de resumo da migração;
- arquivos de referência do plano inicial, já arquivados.

## Objetivo deste repositório

Servir como referência para o histórico do projeto, para a decisão adotada e para a base de entendimento do que foi descartado em favor de uma solução mais pragmática.

## Próximos passos sugeridos

1. Definir os usuários iniciais e o número de licenças do Microsoft 365.
2. Criar a estrutura de arquivos e permissões no ambiente da solução adotada.
3. Migrar os documentos mais importantes e validar o fluxo com os usuários pilotos.
4. Expandir o uso conforme a operação demonstrar necessidade.
