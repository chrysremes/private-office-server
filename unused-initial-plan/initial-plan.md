# Initial Migration Plan

1. Setup a Server Desktop Machine;
 1. Install Linux Ubuntu 26.04 x64 LTS, since it is more user-friendly and already updated and stable;
 2. Set up Linux for storing all the files (docx, xlsx, xlsm, kml) and allowing them to be accessed by Windows machines through the local and remote network;
 3. Setup a WAN (ISP) with fixed-IP to ensure remote access;
2. Connect the local Windows machines to access the Linux Server locally;
3. Connect the remote Windows machines to access the Linux Server remotely, through the Web;
